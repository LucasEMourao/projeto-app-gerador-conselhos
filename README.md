# App Gerador de conselhos

Essa aplicação mostra um card, com um conselho inicial gerado pela API em que foi feito o site. E possui um botão que ao clicar, altera o conselho do card.

## Funcionalidades do site:
- Listagem de conselho no card.
- Um botão para alterar conselhos.

## Ferramentas Utilizadas
- **HTML**: Para a base do projeto.
- **CSS**: Para estilização.
- **JavaScript**: Funcionalidade do evento do clique, para ao clicar no botão alterar o conselho do card.

## Como rodar o projeto:
1. Clone o repositório do mesmo.
2. Coloque para rodar usando o Live Server.

## Desafios, decisões e informações adicionais

O mais difícil mais realmente me adaptar ao uso da linguagem de programação, que era a primeira vez que praticava sozinho, mas fiquei muito feliz com o resultado e vamos por mais. Até breve 😁.
